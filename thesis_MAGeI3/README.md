# MAGeI3 thesis simulation (work in progress)

Open-source 1D drift-diffusion solver (`sim/dd1d.py`) implementing the SCAPS-1D
physical model (Poisson, continuity, SRH, thermionic emission at heterointerfaces,
AM1.5G Beer-Lambert generation). Input parameters from thesis Chapter 3 in `sim/params.py`.

Status: solver runs for no-buffer, WOx and NiOx structures; V2O5 convergence and
validation still in progress.
